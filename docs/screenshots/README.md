## 0.1.3-dev 冻结包的有限验收

归档记录为 12 组受影响 UI 检查，以及 1 组最终身份、日志与清理检查通过。覆盖首次邻页真实结构、取消与提交、首次读取、已访问页面内容保留、文件普通操作菜单、终端输出与草稿、慢速纵向折叠恢复、部分横向手势及抽屉返回。

- 应用仅连接测试模拟器自身的 loopback ADB 服务。
- 预览阶段未提前发起应用业务读取、上传 helper、启动 PTY 或启动投屏。
- 终端离页后关闭旧 PTY，回访建立新 PTY，保留显示与未提交输入，不重放已执行命令。
- 图中的 `/data/local/tmp/gb_neighbor_20261012_v11/` 和 `ordinary_*.txt` 是测试期间创建的普通夹具目录与文件；`QA_NEIGHBOR` 是合成测试输出，不是用户私人内容。
- 远控图只有参数页预览，没有启动视频；进程页是模拟器实际数据，不能据此断言进程指标在所有内核上的含义一致。
- 工具入口可见不等于每个工具都在此轮执行。部分激活预设仍有明确限制，见 [待验清单](../REMAINING_VALIDATION.md)。
- 收尾应用日志未新增 FATAL EXCEPTION、WindowLeaked 或 BadTokenException；系统已有 codec 异常基线保持不变。模拟器已停止，但进程 wait 返回 138，归档没有将其记为正常 exit 0。

本轮没有重跑本机应用选择器、旋转或隐藏文件过滤全套，也不证明 API 19 / 30+、OEM 真机、USB / Fastboot、真实无线配对、投屏、电源控制或完整存储异常已验收。后续源码修改必须按新的 APK 哈希重新验证，不能把这些历史截图当作当前 main 的通过证明。
